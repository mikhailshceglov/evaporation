# evaporation

Проект для обработки часовых данных уровня воды в испарительном баке:

1. **Очистка** от резких скачков (долив/отлив, артефакты измерений).
2. **Детекция и исключение дождя** (AWAT) + вспомогательные маски (например, gate).
3. **Сглаживание тренда** адаптивным фильтром Калмана.
4. (Опционально) **Расчёт испарения**: часовые/полусуточные/суточные величины и вариант с температурной поправкой.

Итоговый результат пайплайна: `result/after_kalman_evap.{csv,xlsx,html}`.

---

## Структура проекта

* `topping_up/` — удаление резких скачков в исходном ряду.
* `rain/` — детекция и удаление дождевых событий (AWAT), интерактивные графики.
* `Kalman_filter/` — сглаживание ряда фильтром Калмана + интерактивная визуализация.
* `data/` — исходные и промежуточные данные (CSV/Excel).
* `result/` — финальные артефакты после Калмана (CSV/XLSX/HTML).
* `plots/` — дополнительные графики/визуализации (если используются).

**Краткий вывод:** проект организован как последовательный пайплайн; каждая папка отвечает за отдельный этап обработки.

---

### Этап 1. Удаление резких скачков (долив/отлив/артефакты)

python3 topping_up/data_cleaner.py

```bash
python3 topping_up/interactive_cleaner.py
xdg-open topping_up/cleaned_data_plot.html
```

**Выходные файлы:**

* `data/cleaned_data.xlsx`
* `data/cleaned_data.csv`

**Краткий вывод:** на этом шаге убираются резкие скачки, чтобы дальнейшие алгоритмы не путали их с дождём/трендом.

---

### Этап 2. Детекция дождевых событий (AWAT)

**Файл:** `rain/apply_awat.py`

Пример запуска:

```bash
python3 rain/apply_awat.py \
  --in data/cleaned_data.csv \
  --dt-col datetime \
  --y-col level_cleaned_mm \
  --noise-eps 0.086 \
  --min-noise-len 15 \
  --gap-minutes 10
```

Параметры:

* `--in` — входной CSV после этапа 1.
* `--dt-col` — столбец с датой/временем.
* `--y-col` — столбец с уровнем воды.
* `--noise-eps` — порог для детекции (чувствительность).
* `--min-noise-len` — минимальная длина сегмента (в точках).
* `--gap-minutes` — допустимая «дырка» между сегментами перед объединением.

Интерактивная визуализация найденных сегментов:

**Файл:** `rain/interactive_plot.py`

```bash
python3 rain/interactive_plot.py
xdg-open rain/out/interactive_plot.html
```

Подсказка по цветам (если включено в графике):

* синий — сегменты дождя
* оранжевый — сегменты gate (если применяются)

**Краткий вывод:** AWAT выделяет интервалы, где рост уровня похож на осадки, чтобы исключить их из расчёта испарения.

---

### Этап 3. Удаление дождя из ряда

**Файл:** `rain/remove_rain.py`

```bash
python3 rain/remove_rain.py \
  --in rain/out/out.csv \
  --out rain/out/evap_only.csv \
  --out-html rain/out/evap_only.html \
  --dt-col datetime \
  --y-col y
```

Просмотр результата:

```bash
xdg-open rain/out/evap_only.html
```

**Выходные файлы:**

* `rain/out/evap_only.csv`
* `rain/out/evap_only.html`

**Краткий вывод:** после этого шага ряд должен описывать поведение уровня без дождевых интервалов.

Интерактивный просмотр итогового сглаживания:

## Расчёт испарения (после пайплайна)

> Этот блок используется, если в проекте подключены скрипты расчёта испарения поверх финального ряда `result/after_kalman_evap.csv`.

### Часовое / полусуточное / суточное испарение

**Файл:** `calc_evaporation.py`

```bash
python3 calc_evaporation.py
```

**Результаты:** `calc_result/`

* `evap_hourly.xlsx` — часовые значения
* `evap_half_daily.xlsx` — полусуточные (00–12, 12–24)
* `evap_daily.xlsx` — суточные
* `*.csv` — при наличии, те же данные в CSV

**Краткий вывод:** из финального ряда считаются разности уровня по времени и агрегируются в 1ч/12ч/24ч.

---

### Испарение с температурной поправкой

**Файл:** `calc_evaporation_corrected.py`

```bash
python3 calc_evaporation_corrected.py
```

**Результаты:** `calc_result_with_temperature/`

**Краткий вывод:** температурная поправка отделяет «изменение уровня из-за расширения воды» от реального испарения.
